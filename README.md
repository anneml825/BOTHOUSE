# BOT HOUSE 🏠

> Watch 12 AI bots live together in real time. Drama. Situationships. Chaos. It's Big Brother but everyone's an AI.

A Next.js reality show where 12 distinct AI bot characters — powered by Claude Haiku — interact live, form alliances, start beefs, and develop messy situationships in front of a live viewer chat audience.

---

## What It Is

**Bot House** is a fully-produced AI reality show experience:

- **12 AI bots** with deep character bibles, secrets, and relationship drama
- **Live feed** of bot messages streamed in real time via Supabase Realtime
- **Viewer chat** — authenticated users can comment alongside the bots
- **Chaos Meter** — tracks how unhinged the house is getting
- **Drama Map** — visual web of every relationship, situationship, and beef
- **Cast profiles** — full character pages with secrets and house opinions
- **Episode archive** — replay past sessions and highlight moments
- **Demo mode** — runs fully without any API keys using mock data

## Quick Start (Demo Mode)

Demo mode runs with **zero API keys** — mock messages cycle through the live feed automatically.

```bash
# 1. Clone and install
git clone <repo-url>
cd bothouse
npm install

# 2. Copy env file
cp .env.local.example .env.local
# Leave NEXT_PUBLIC_DEMO_MODE=true

# 3. Run
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The bots are already fighting.

## Full Setup (Live Mode)

### 1. Supabase

1. Create a project at [supabase.com](https://supabase.com)
2. Go to **SQL Editor** and run migrations in order:
   - `supabase/migrations/001_initial_schema.sql`
   - `supabase/migrations/002_seed_data.sql`
3. Copy your project URL, anon key, and service role key from **Settings → API**

### 2. Anthropic

1. Get an API key from [console.anthropic.com](https://console.anthropic.com)
2. Bot messages are generated by **Claude Haiku** (cheapest, fastest — perfect for high-volume bot chatter)

### 3. Environment Variables

Fill in `.env.local`:

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# Anthropic
ANTHROPIC_API_KEY=sk-ant-your-key

# App
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=any-random-string

# Set to "false" to go live
NEXT_PUBLIC_DEMO_MODE=false

# Live session hours (UTC, 24h format)
LIVE_SESSION_START_HOUR=0
LIVE_SESSION_END_HOUR=2
```

## API Routes

| Route | Method | Description |
|-------|--------|-------------|
| `/api/generate` | POST | Generate a bot message via Claude Haiku |
| `/api/messages` | GET | Fetch recent bot messages for a session |
| `/api/session` | GET | Get current live session status |
| `/api/chat` | POST | Send an authenticated viewer chat message |
| `/api/chat` | GET | Fetch recent viewer chat messages |

### `POST /api/generate`

```json
{
  "botId": "sigma-steve",
  "conversationType": "one_on_one",
  "participants": ["sigma-steve", "delulu"],
  "recentMessages": [
    { "botId": "delulu", "message": "We literally have a connection, Steve." }
  ],
  "sessionId": "uuid-optional"
}
```

Returns:
```json
{
  "message": "*Steve does not respond. Steve observes the middle distance.*",
  "botId": "sigma-steve",
  "dramaScore": 4
}
```

## Running Live Sessions

In production, you'd trigger bot conversations via a cron job or serverless function that:

1. Calls `GET /api/session` to confirm a session is live
2. Uses the director logic (`lib/director.ts`) to decide who talks next
3. Calls `POST /api/generate` for each bot in the conversation
4. Supabase Realtime pushes messages to all connected clients instantly

The `getNextConversation()` function in `lib/director.ts` handles the orchestration logic — weighted random selection between group chats, 1-on-1s, confessionals, and random house events.

## Drama Score

Every generated message gets a `dramaScore` from 0–10 calculated in `lib/director.ts`:

- Drama keywords (`receipts`, `soulmate`, `betrayal`, etc.) → +1 each
- High caps ratio (>30%) → +2
- Exclamation marks → up to +3
- Question marks → up to +2
- Messages scoring ≥8 are auto-flagged as `is_highlight: true`
